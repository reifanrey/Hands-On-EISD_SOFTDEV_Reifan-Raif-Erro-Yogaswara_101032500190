# Hands-On-EISD_SOFTDEV_Reifan-Raif-Erro-Yogaswara_101032500190
Seleksi Study Group EISD tahap Hands-on Assignment Software Development

Soal non-Coding
Masalah :
    1. input data yang lebih dari satu, 
    2. Data yang diinput tidak valid atau tidak sesuai,
    3. Kuota yang melebihi batas,
    4. Tidak jelas data mana yang resmi atau valid.
Kondisi saat itu :
    Saya sedang membantu perbaiki website versi lebih baik, tapi terkendala di waktu yang sangat terbatas yang membuat saya menentukan prioritas perbaikan website tersebut, dan saya cuman bisa memperbaiki 1 hal pada website tersebut.
Solusi : 
    Prioritas saya adalah menambahkan validasi input pada form pengisian.
Alasannya :
    1. Validasi input, Ketika user sudah menekan submit 1 kali sistem validasi akan otomatis menutup tombol pendaftaran mencegah data masuk berkali - kali,
    2. Validasi input akan memberi peringatan "Required"/"invalid data" kepada user ketika inputnya tidak sesuai, atau diisi kosong mencegah data-data yang tidak jelas dan berantaka,
    3. Kenapa saya tidak memprioritaskan solusi kuota yang  melebihi batas karena kuota yang sudah melebihi batas bisa di seleksi ulang oleh panitia secara manual yang penting data yang diinput itu valid, resmi, dan tidak berantakan.
